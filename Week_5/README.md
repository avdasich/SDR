# Неделя 5. Приём и передача на двух Pluto

В [main.c](../main.c) одна программа с двумя режимами: `tx` передаёт сигнал, `rx` принимает и пишет его в PCM.

Обе платы настроены на 800 МГц, частота дискретизации — 1 МГц. В коде стоят RX gain=30 и TX gain=40. На передачу идёт 4 мс I=Q=2000, затем 300 мс нулей.

На передающей плате RX тоже включён: по его временной метке передача назначается на 4 мс позже. Размеры буферов программа получает через `getStreamMTU`.

После сборки сначала запускается приёмник, потом передатчик на второй плате:

```bash
./build/sdr rx USB_URI_RX rx_new.pcm
./build/sdr tx USB_URI_TX
```

Вместо `USB_URI_RX` и `USB_URI_TX` подставляются адреса из `SoapySDRUtil --find`. Остановка — Ctrl+C.

Программа создаёт потоки, передаёт отсчёты и сохраняет принятые I/Q. Синтаксис проверен; эту версию с прямоугольным импульсом ещё нужно проверить на платах. В следующем отчёте разобрана запись более раннего двухтонового варианта.
