# Двухтоновый передатчик

Вариант программы с двумя тонами: 2 мс на 5 кГц, 2 мс на 10 кГц и 300 мс нулей. Частота дискретизации — 1 МГц.

По этому сигналу разобрана запись в [отчёте за 6-ю неделю](../../Week_6/README.md).

В этой версии приём заменяет `rxdata.pcm`. Запускать её нужно в отдельной папке без старой записи.
